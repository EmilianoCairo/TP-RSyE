# Trabajo final Redes Sociedad y Economía, FCEyN, UBA

Este proyecto es una aplicación web interactiva construida con Streamlit para el análisis y la visualización de la red de colaboraciones científicas de la Facultad de Ciencias Exactas y Naturales (FCEyN). 
Fue hecho como trabajo final de la materia Redes, Sociedad y Economía cursada en la misma facultad de los datos en el 1°C de 2024.
El objetivo es caracterizar la topología de esta red para comprender cómo se interconectan los investigadores y quiénes son los actores centrales. 

## Para correr la aplicación localmente
1. Clonar el repositorio:
```
git clone https://github.com/EmilianoCairo/TP-RSyE.git
```
2. Activar un ambiente virtual:
```
python3 -m venv venv  
source venv/bin/activate
```
3. Instalar las dependencias:
```
pip install -r requirements.txt
```
5. Ejecutar la aplicación con:
```
streamlit run streamlit_app.py
```

## Para visualizar la aplicación directamente
Ingresar directamente al link: https://tp-rsye.streamlit.app
